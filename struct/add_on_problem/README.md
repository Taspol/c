## เตรียมก่อนเริ่มจับเวลา

เหมาะกับน้องที่เคยเห็นตัวแปร `int`, `float`, `char` รวมถึง `if`, `for` และ array มาบ้าง พี่เตรียม editor กับ terminal ไว้ก่อน จะได้ใช้ 15–20 นาทีไปกับการเข้าใจ ไม่ใช่ติดตั้งโปรแกรม

ต้องมี Python 3 และ C compiler (`cc`, `clang` หรือ `gcc`) ไม่ต้องลง Python package เพิ่ม บน macOS ใช้ Xcode Command Line Tools บน Windows ใช้ WSL หรือ terminal ที่ติดตั้ง GCC แล้ว คำสั่งด้านล่างใช้ terminal แบบ macOS/Linux/WSL

เปิด terminal ในโฟลเดอร์แพ็กเกจ แล้วลองตรวจเฉลยเพื่อเช็กเครื่อง:

```sh
python3 test.py --solution
```

ตอนฝึก แก้ `practice.c` แล้วรัน:

```sh
python3 test.py
```

ไฟล์เริ่มต้นคอมไพล์ได้แต่ตั้งใจให้ test ยังไม่ผ่าน พอเติมครบจึงควรผ่านทั้งหมด ถ้าไม่มี `cc` แต่มี `gcc` ใช้ `CC=gcc python3 test.py` ได้ ตัวทดสอบสร้างโปรแกรมในโฟลเดอร์ชั่วคราวและลบเมื่อจบ

## 1 ลองออกแบบบัตรนักดนตรี

**พี่ชวนคุย:** “ถ้าเรามีเพื่อน 3 คน จะตั้ง `name1`, `name2`, `age1`, `age2` ไปเรื่อย ๆ ก็ได้ แต่ถ้ามี 2,000 คนเหมือนในสไลด์ เราจะจับคู่ชื่อกับอายุไม่ให้สลับกันยังไง?”

`struct` คือชนิดข้อมูลที่รวมสมาชิกหลายชนิดไว้ใต้ชื่อเดียว เช่น ชื่อเป็นข้อความ อายุเป็นจำนวนเต็ม ราคาเป็นทศนิยม การประกาศแบบแปลนยังไม่ใช่การสร้างตัวแปรของคนจริง ๆ

```c
struct musician {
    char name[30];
    int age;
    char instrument[20];
};
struct musician hero, friend;
```

อ่านว่า “มีแบบแปลนชื่อ `struct musician` แล้วสร้างตัวแปร `hero` และ `friend` ตามแบบนั้น” อย่าลืม `;` หลัง `}`

อีกแบบหนึ่งรวมการสร้างตัวแปรไว้ท้ายแบบแปลนเลย ผลเหมือนกัน เลือกใช้แบบใดแบบหนึ่ง:

```c
struct musician {
    char name[30];
    int age;
    char instrument[20];
} hero, friend;
```

ตัวอย่างนักเรียนในสไลด์ใช้ name, surname, age, gender ส่วนสินค้าใช้ name, count, price และรายได้ใช้ salary, bonus, age หลักเดียวกันหมด: เลือกชนิดของแต่ละช่องให้ตรงกับข้อมูล

**ให้น้องตอบ:** ถ้าบัตรมี “จำนวนเพลงที่ซ้อม” จะเลือก `int` หรือ `char[]`? → `int` เพราะเอาไปนับได้

## 2 จุดคือการชี้ช่องในบัตร

```c
hero.age = 18;
strcpy(hero.name, "Mali");
strcpy(hero.instrument, "Violin");
```

`hero.age` อ่านว่า “อายุของ hero” ส่วน `strcpy` ต้องใส่ `#include <string.h>` และปลายทางต้องมีที่ว่างพอรวมตัวจบข้อความ `\0` ด้วย ตัวอย่างที่ให้ใช้ข้อความสั้นซึ่งใส่ในช่องได้แน่นอน

| ตัวแปร | name | age | instrument |
|---|---|---:|---|
| hero | Mali | 18 | Violin |
| friend | ยังไม่ได้กำหนด | ยังไม่ได้กำหนด | ยังไม่ได้กำหนด |

ตัวแปร local ที่ยังไม่กำหนดค่า ห้ามหยิบมาใช้แบบเดาว่าเป็นศูนย์นะ

**พี่ถาม:** “เปลี่ยนชื่อด้วย `hero.name = "Mali";` ได้ไหม?” → ไม่ได้ เพราะ `name` เป็น array ของ char ไม่สามารถใช้ `=` ยกข้อความมาแทนทั้ง array หลังประกาศได้ ใช้ `strcpy` สำหรับตัวอย่างนี้ ส่วนตัวเลขอย่าง `hero.age = 18;` ใช้ได้เลย

ตัวอย่างรายได้ในสไลด์ก็เป็นการเติมช่องแบบเดียวกัน:

```c
struct income { float salary; float bonus; int age; } person;
person.salary = 16000;
person.bonus = 40000;
person.age = 23;
```

## 3 ใส่ค่าเริ่มต้น แล้วซื้อหนังสือโน้ต

```c
struct book {
    char name[50];
    float price;
    float discount;
};
struct book b = {"Violin Basics", 200.0f, 0.0f};
b.discount = b.price * 0.10f;
printf("%.2f\n", b.price - b.discount);
```

ตอนประกาศใช้ `{"ข้อความ", ตัวเลข, ตัวเลข}` ได้ เพราะเป็นการกำหนดค่าเริ่มต้น ต้องเรียงตามสมาชิก: name → price → discount อย่าสลับเป็น `{200, "Violin Basics", 0}` ตัว `f` ท้ายเลขหมายถึง float ส่วน `%.2f` ให้พิมพ์ทศนิยมสองตำแหน่ง

**หยุดเดาก่อน:** ราคา 200 ส่วนลดเท่าไร จ่ายจริงเท่าไร? → ลด 20 จ่าย 180 ทีนี้เติม TODO 1 ใน `practice.c` ให้บัตรหนังสือโน้ตชื่อ Keyboard Songs ราคา 200 ลด 10% ได้ตามนี้

### รับข้อมูลจากคีย์บอร์ดอย่างไร

```c
scanf("%f", &b.price);  /* float ใช้ %f และส่งที่อยู่ด้วย & */
scanf("%49s", b.name); /* array ข้อความไม่ใส่ & แต่ %s หยุดเมื่อเจอช่องว่าง */
```

ถ้าชื่อเป็น `Programming in TurboC` แบบหน้า 12 ให้ใช้ `fgets(b.name, sizeof b.name, stdin)` แล้วตัด newline ออกด้วย `b.name[strcspn(b.name, "\n")] = '\0';` จึงจะรับครบทั้งชื่อ ดูโปรแกรมเต็มที่ [examples/book.c](examples/book.c) ซึ่งรับชื่อก่อนราคา และตรวจว่ารับข้อมูลสำเร็จ ข้อจำกัด: ชื่อไม่เกิน 49 ไบต์ ราคาไม่ติดลบและอยู่ในช่วงตัวอย่างทั่วไป

`char name[50]` จุข้อความได้ไม่เกิน 49 ไบต์บวก `\0` ไม่ได้หมายถึงภาษาไทย 49 ตัวอักษรเสมอไป แบบฝึกจึงใช้ชื่อภาษาอังกฤษเพื่อโฟกัส struct

## 4 มีหลายคน ใช้ array แล้วไล่ทีละบัตร

```c
struct musician band[3] = {
    {"Mali", 18, "Violin"},
    {"Beam", 20, "Keyboard"},
    {"Fah", 23, "Violin"}
};
```

`band` มี 3 คน index คือ 0, 1, 2 ไม่ใช่ 1, 2, 3 ถ้าต้องการ 10 คนใช้ `struct musician band[10];` หรือประกาศต่อท้าย `} band[10];` ก็ได้เหมือนสองรูปแบบก่อนหน้า

**พี่ชวนไล่นิ้ว:** “อ่าน `band[2].age` จากซ้ายไปขวา เลือกคนช่อง 2 ก่อน แล้วหยิบอายุ จะได้เท่าไร?” → 23

ลองกติกาเดียวกับสไลด์: แสดงคนที่อายุ **มากกว่า 20**

| i | band[i].name | band[i].age | age > 20 | พิมพ์ไหม |
|---:|---|---:|---|---|
| 0 | Mali | 18 | เท็จ | ไม่พิมพ์ |
| 1 | Beam | 20 | เท็จ | ไม่พิมพ์ |
| 2 | Fah | 23 | จริง | Fah,23 |

```c
for (int i = 0; i < 3; i++) {
    if (band[i].age > 20) {
        printf("%s,%d\n", band[i].name, band[i].age);
    }
}
```

ไปเติม TODO 2–3 ใช้ `n` แทนเลข 3 เพราะ test จะส่งวงที่มีขนาดต่างกันมาให้ อายุ 20 พอดีไม่ผ่าน อย่าเผลอใช้ `>=` สไลด์รับ 10 คนจากคีย์บอร์ดก่อน แล้วค่อยวนอีกรอบเพื่อกรอง ดู [examples/students.c](examples/students.c) ซึ่งใช้ขั้นตอนนี้ตรง ๆ

## 5 วาดการ์ตูนแล้วเก็บตำแหน่งไว้ด้วย

ตัวการ์ตูนต้องมีตำแหน่ง x กับ y ลองรวมสองค่านี้เป็น `struct point` แล้ววางไว้ในบัตรนักดนตรี นี่คือ **nested structure** หรือ struct ซ้อน struct

```c
struct point { int x; int y; };
struct performer {
    char name[30];
    struct point sticker;
};
struct performer hero = {"Mali", {10, 20}};
hero.sticker.x = hero.sticker.x + 5;
```

ตัวอย่างนี้กำหนดว่า x เพิ่มคือขยับขวา 5 หน่วย y เท่าเดิม ตำแหน่งใหม่คือ (15, 20) เราเก็บข้อมูลไว้ส่งต่อให้โปรแกรมวาดภาพได้ แต่ struct เองไม่ได้วาดให้

```text
hero
 ├── name = "Mali"
 └── sticker                  ← struct point ที่อยู่ข้างใน
      ├── x = 10              ← hero.sticker.x
      └── y = 20              ← hero.sticker.y
```

**พี่พูด:** “จุดแต่ละอันเหมือนเปิดช่องเข้าไปอีกชั้น ชื่อคน → ตำแหน่งสติกเกอร์ → ค่า x” ไปเติม TODO 4 ให้ขยับ x จากค่าเดิม แล้ว TODO 5 เปลี่ยนชื่อเป็น Mint ด้วย `strcpy`

ในสไลด์ นักเรียนมีทั้ง `struct address add` และ `struct phone tel` จึงอ่านได้เป็น `student.add.road` กับ `student.tel.mobile` ข้อมูลซ้อนหลายกิ่งได้ ไม่จำเป็นต้องมีแค่กิ่งเดียว เบอร์โทรและรหัสควรเก็บเป็นข้อความเพื่อรักษาเลขศูนย์นำหน้า ต้องเผื่อ `\0` ด้วย เช่น เบอร์ 10 หลักต้องมีอย่างน้อย `char mobile[11]` ช่อง `[10]` ในสไลด์ไม่พอสำหรับเบอร์ 10 หลักพร้อมตัวจบ

ตัวอย่างมหาวิทยาลัยใช้แนวเดียวกัน: `king.name` เป็นชื่อ และ `king.place.add`, `.moo`, `.road`, `.district`, `.province` เป็นที่อยู่ ดูโค้ดเต็ม [examples/nested.c](examples/nested.c)

### ตาราง ต้นไม้ หรือกราฟ อะไรง่ายสุด

ไม่มีแบบที่ง่ายสุดทุกสถานการณ์ พี่แนะนำให้เปลี่ยนภาพตามคำถาม:

| อยากรู้อะไร | ใช้ภาพไหน | เพราะอะไร |
|---|---|---|
| คนไหนอายุเกิน 20 | ตาราง | เทียบค่าหลายคนในคอลัมน์เดียว |
| `hero.sticker.x` อยู่ตรงไหน | ต้นไม้ด้านบน | เห็นชั้นของข้อมูลทันที |
| ลูปทำอะไรก่อนหลัง | ผังการไหลด้านล่าง | เห็นการตรวจเงื่อนไขและย้อนกลับ |
| ตัวการ์ตูนย้ายไปไหน | จุดบนระนาบ x,y | เห็นตำแหน่งก่อนและหลัง |

```text
เริ่ม i = 0 → i < n ? ── ไม่ใช่ → จบ
                │ ใช่
                ↓
           อายุ > 20 ? ── ใช่ → พิมพ์ชื่อและอายุ
                │ ไม่ใช่                │
                └──────────┬────────────┘
                           ↓
                         i++ → กลับไปถาม i < n
```

```text
 y
20 |          ● Mali ─────→ ● Mali
   |         (10,20)      (15,20)
 0 +-------------------------------- x
   0          10           15
```

เส้นในภาพต้นไม้หมายถึง “มีข้อมูลนี้อยู่ข้างใน” ไม่ใช่ pointer และไม่ต้องเรียนโครงสร้างข้อมูล graph เพิ่มเพื่อเข้าใจบทนี้

## 6 ก่อนจบ เจอโจทย์ byte อย่าบวกอย่างเดียว

หน้า 29 มี `char name[30]` กับ `float salary` จำนวน 3 คน ถึงมีค่าเริ่มต้น 6 ค่า ก็เป็น **3 struct** ไม่ใช่ array 6 ตัว

ขนาดจริงต้องใช้ `sizeof` เพราะ compiler อาจเว้นช่องว่างที่เรียกว่า padding เพื่อจัดแนวข้อมูล บนระบบทั่วไปที่ float ขนาด 4 ไบต์และต้องจัดแนว 4 ไบต์ จะได้แบบนี้:

```text
หนึ่งคน: [ name 30 ไบต์ ][ ว่าง 2 ][ salary 4 ] = 36 ไบต์
สามคน:  [       36     ][   36  ][    36    ] = 108 ไบต์
```

ดังนั้นข้อความ “ใช้ 102 ไบต์” ในข้อ 5 หน้า 29 ไม่ใช่ข้อสรุปที่ใช้ได้ทุกเครื่อง ส่วนข้อ 4 ที่บอก array มี 6 ตัวผิดแน่นอน ถ้าข้อสอบสมมติว่าไม่คิด padding และ float = 4 ก็จะคำนวณ 102 ได้ ต้องแยกสมมติฐานของโจทย์กับผลจริงบนเครื่อง

หน้า 30 ตัวเลือก `char name[8]; float money;` มักมีขนาด 12 ไบต์บนระบบที่ใช้ float 4 และ alignment 4 แต่ C ไม่รับประกันขนาดชนิดเหล่านี้เท่ากันทุกเครื่อง เรามี [examples/memory.c](examples/memory.c) ให้พิมพ์ `sizeof` กับตำแหน่ง field จริง ไม่บังคับ test ว่าทุกเครื่องต้องได้ 108

**เช็กจบ 3 คำถาม:**

1. ทำไม `hero.name = "Mint";` ใช้ไม่ได้ และจะแก้อย่างไร?
2. คนอายุ 20 ผ่าน `age > 20` ไหม และ array ของ 10 คนใช้ index ไหนถึงไหน?
3. อ่าน `hero.sticker.x` ว่าอะไร และทำไมขนาด struct อาจเกินผลบวกของสมาชิก?

## ลองตัวอย่างเต็มหลังคาบ

```sh
cc -std=c11 -Wall -Wextra -pedantic examples/book.c -o /tmp/struct-book
/tmp/struct-book
```

เปลี่ยน `book.c` เป็น `students.c`, `nested.c` หรือ `memory.c` และเปลี่ยนชื่อโปรแกรมปลายทางตามต้องการ โปรแกรม book รับชื่อหนึ่งบรรทัดแล้วราคาหนึ่งบรรทัด โปรแกรม students รับชื่อและอายุรวม 10 คน ชื่อมีช่องว่างได้สูงสุด 19 ไบต์ ตัวอย่างเหล่านี้ใช้ `int main(void)` และ standard library ไม่ต้องใช้ `conio.h` แบบสไลด์เก่า
