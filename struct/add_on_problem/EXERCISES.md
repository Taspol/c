# ใบโจทย์ใหญ่ เตรียมโชว์ดนตรีกับตัวการ์ตูน

น้องเป็นคนจัดรายชื่อวงและออกแบบโปสเตอร์ เป้าหมายคือเก็บข้อมูลให้อยู่เป็นชุด ซื้อหนังสือโน้ตลดราคา เลือกสมาชิกอายุเกิน 20 และย้ายตัวการ์ตูนบนโปสเตอร์ ใช้ README เดินไปด้วยกัน ไม่ต้องทำทั้งใบภายใน 20 นาที

## ภารกิจในคาบ เติม practice.c

พี่เตรียม `struct book`, `struct point`, `struct musician` และ main ให้แล้ว ฟังก์ชันเป็นแค่การแบ่งงานเป็นช่อง ๆ น้องเติมเฉพาะ TODO ได้ ไม่ต้องรู้ pointer เพิ่มในคาบนี้ ฟังก์ชันที่รับ `hero` ทำงานกับสำเนาแล้วส่งค่าที่แก้กลับด้วย `return` ตอนนำไปใช้ต้องรับค่านั้นเหมือนที่ main ทำ

| จุดเติม | สิ่งที่ต้องทำ | ผลที่ต้องได้ |
|---|---|---|
| TODO 1 | สร้างหนังสือ Keyboard Songs ราคา 200 แล้วคำนวณส่วนลด 10% | ส่วนลด 20 จ่าย 180 |
| TODO 2 | วนผ่านสมาชิก `n` คนด้วย index | ใช้ได้ทั้ง 0, 1, 3 หรือ 10 คน |
| TODO 3 | พิมพ์เฉพาะคนอายุ > 20 คนละบรรทัด | `ชื่อ,อายุ` ไม่เว้นวรรคเพิ่ม |
| TODO 4 | เพิ่ม x ด้วย `step` เก็บสมาชิกอื่นเหมือนเดิม | (10,20) ขยับ 5 ได้ (15,20) |
| TODO 5 | เปลี่ยนชื่อเป็น Mint เก็บสมาชิกอื่นเหมือนเดิม | ใช้ strcpy กับช่อง name |

ลำดับลงมือ: เดาผล → เติม TODO → `python3 test.py` → อ่านชื่อเคสที่พลาด → กลับไปดูช่องในตารางหรือกิ่งในต้นไม้ ถ้าเจอ `20` ถูกพิมพ์ ให้ดูเครื่องหมายเปรียบเทียบก่อน

ลองรันเองนอก test ได้:

```sh
cc -std=c11 -Wall -Wextra -pedantic practice.c -o /tmp/struct-tutor
/tmp/struct-tutor book
/tmp/struct-tutor band
/tmp/struct-tutor move
/tmp/struct-tutor rename
```

ผลหลังทำครบ ตามลำดับคำสั่ง:

```text
Keyboard Songs|200.00|20.00|180.00
Fah,23
Mali|15|20
Mint|Violin
```

ชุดทดสอบตรวจผลลัพธ์ของฟังก์ชัน และเช็กว่าข้อมูลที่ไม่เกี่ยวข้องไม่เปลี่ยน ผู้สอนยังควรดูว่าใช้ struct, loop และ strcpy ตามบทเรียนจริง ไม่เขียนผลลัพธ์ตายตัวให้ผ่านแค่ตัวอย่าง

### F2 หน้า 29 อ่านค่าและขนาด

```c
struct profile { char name[30]; float salary; };
struct profile a[] = {{"John", 3000}, {"Tiger", 2000}, {"Lisa", 5000}};
```

จัดวงเล็บปีกกาให้เห็นแต่ละคนชัดขึ้นจากสไลด์ ค่าและจำนวนสมาชิกเท่าเดิม บอกว่าข้อใดถูก ผิด หรือขึ้นกับสมมติฐาน:

1. a[0].name เก็บข้อความ John
2. a[0].salary + a[1].salary เท่ากับ 5000
3. a[1].salary เท่ากับ 2000
4. a มีสมาชิก 6 ตัว
5. a ใช้พื้นที่ 102 ไบต์

ลอง `sizeof` ใน examples/memory.c แล้วอธิบายว่าทำไมข้อ 5 อาจต่างจากการบวกขนาดเอง

### F3 หน้า 30 ข้อไหนใช้ 12 ไบต์

สมมติ char = 1, int = 4, float = 4, double = 8 ไบต์ และใช้ alignment ตามเครื่องทั่วไป (int/float 4, double 8) แก้ `;` ที่ตกหล่นในข้อ 1 ของสไลด์แล้ว:

1. `struct data { int item; double price[3]; } A;`
2. `char i[3][3]; int a_str;`
3. `struct data { char name[8]; float money; } A;`
4. `int i[3][4]; char a_str;`
5. ไม่มีข้อถูก

ข้อ 2 และ 4 ให้นับผลรวม sizeof ของตัวแปรทั้งสอง ไม่รวมช่องว่างที่ compiler อาจใช้วางตัวแปร local แยกกัน เลือกคำตอบและอธิบายแต่ละข้อ แล้วค่อยเปิด solutions/ANSWERS.md
