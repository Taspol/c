# เฉลยสำหรับพี่ผู้สอน

ให้น้องอธิบายสิ่งที่เดาก่อนเปิดไฟล์นี้ ถ้า test ไม่ผ่าน ให้ชี้ชื่อเคสแล้วชวนน้องกลับไปดูตารางหรือภาพต้นไม้ อย่าเพิ่งแทนไฟล์น้องด้วยเฉลยทั้งไฟล์

## ภารกิจในคาบ

โค้ดเต็มอยู่ที่ [practice.c](practice.c) ตรวจด้วย `python3 test.py --solution` จากโฟลเดอร์หลัก

1. `struct book b = {"Keyboard Songs", 200.0f, 0.0f};` แล้ว `b.discount = b.price * 0.10f;` จึงได้ส่วนลด 20 และราคาสุทธิ 180
2. วน `for (int i = 0; i < n; i++)` ใช้ n เพื่อทำงานได้กับจำนวนสมาชิกที่ส่งเข้ามาจริง
3. `if (band[i].age > 20)` แล้วพิมพ์ `printf("%s,%d\n", band[i].name, band[i].age);` อายุ 20 พอดีไม่ผ่าน
4. `hero.sticker.x = hero.sticker.x + step;` เปลี่ยน x ช่องเดียว ไม่ต้องแตะ y ค่าลบใน test เป็นการลองสูตรเดิมให้ขยับซ้าย ไม่ใช่หัวข้อใหม่
5. `strcpy(hero.name, "Mint");` ใช้ได้เพราะช่อง name มีที่พอสำหรับ 4 ตัวอักษรและ `\0`

คำถามปิดคาบ: `name` เป็น char array จึงใช้ `=` เปลี่ยนทั้งข้อความหลังประกาศไม่ได้; array 10 ตัวใช้ index 0–9; `hero.sticker.x` คือค่า x ของ sticker ใน hero; padding คือพื้นที่ว่างที่ compiler อาจเพิ่มเพื่อจัดแนวข้อมูล

## A ออกแบบบัตร

name และ instrument ใช้ char array, age และจำนวนเพลงใช้ int รูปแบบแรกจบแบบแปลนด้วย `};` แล้วประกาศ `struct musician hero;` อีกรูปแบบจบด้วย `} hero;` จะมีตัวแปรทันที ทั้งสองแบบต้องมี semicolon

## B ชื่อและลำดับ

ข้อ 1 ถูก name มาก่อน price ข้อ 2 ผิดเพราะสลับชนิดและลำดับ ข้อ 3 ใช้ `strcpy(b.name, "Piano for Two");` พร้อม include string.h ข้อ 4 `%s` อ่านแค่ Piano; `fgets` รับได้ทั้งบรรทัดภายในขนาด buffer แล้วตัด newline ออก การรับข้อมูลตัวอย่างใช้ชื่อไม่ยาวเกินช่องที่กำหนด

## C หนังสือ

ราคา 350 ลด 35 เหลือ 315 ราคา 0 ลด 0 เหลือ 0 name และ price รับจากผู้ใช้ discount คำนวณจาก price ส่วนราคาสุทธิในตัวอย่างคำนวณตอนพิมพ์ ไม่ได้มี field แยก

สไลด์หน้า 13 ใช้ `%s` แต่ผลตัวอย่างหน้า 12 มีชื่อหนังสือหลายคำ เราจึงใช้ fgets ในตัวอย่างเต็มเพื่อให้พฤติกรรมตรงกับชื่อในสไลด์ โค้ดแบบฝึกใช้ float ตามบทเรียน ตัวเลขทศนิยมอาจมีการปัดเศษ; ระบบเงินที่ใช้จริงควรออกแบบการแทนจำนวนเงินให้เหมาะสม เป็นเรื่องต่อยอดหลังบทนี้

## D นักเรียน 10 คน

ผลคือ jo,23 / pat,21 / tu,25 / tee,34 / bat,44 / phon,33 ตามลำดับ แต่ละคนอยู่คนละบรรทัด boy อายุ 20 จึงไม่ผ่าน เงื่อนไข `i <= 10` จะพยายามเข้าถึง s[10] ซึ่งอยู่นอก array และทำให้เกิด undefined behavior ต้องใช้ `i < 10`

## E ข้อมูลซ้อน

เพิ่ม x แล้ว y ไม่เปลี่ยน ใช้ `st.add.road` กับ `st.tel.mobile` สำหรับนักเรียน ส่วน king ใช้ `king.place.add`, `king.place.road`, `king.place.province`

```text
King Mongkut's Institute of Technology Ladkrabang
Address: 3 Moo 2, Chalongkrung Rd.
Ladkrabang, Bangkok
```

ตัวอย่าง nested.c คงสมาชิกของที่อยู่ตามสไลด์ ส่วนภาพการ์ตูนใช้ x,y เป็นบริบทใหม่ที่มีแนวคิดการเข้าถึงแบบเดียวกัน

| ตัวเลือก | คำนวณ | ไบต์ |
